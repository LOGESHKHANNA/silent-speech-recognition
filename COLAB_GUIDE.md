# Google Colab Guide

## 1. Prepare the dataset

Use class folders. The first folder below the dataset root becomes the speech class:

```text
silent_speech_dataset/
  HELLO/
    sample_001.mp4
    sample_002.mp4
  THANK_YOU/
    sample_003.mp4
```

For speaker-aware evaluation, use:

```text
silent_speech_dataset/
  HELLO/
    SPEAKER_01/sample_001.mp4
    SPEAKER_02/sample_002.mp4
```

Run this in the first cell:

## 3. Set the dataset path

Edit this line in the configuration section:

```python
DATA_ROOT = Path("/content/drive/MyDrive/silent_speech_dataset")
```

The script mounts Google Drive and writes cleaned manifests, cached ROI sequences, the trained model, class names, plots, and evaluation metrics to `/content/ssr_outputs`.

## 4. Run in order

Run the cells from top to bottom. If the dataset, vocabulary, or preprocessing settings change, set:

```python
USE_CACHE = False
```

The final evaluation cell calculates accuracy, precision, recall, F1-score, a classification report, and a confusion matrix from the held-out test split.

## 5. Report responsibly

Only copy the values generated by `evaluation_metrics.json` into the website/report. The supplied PBL report does not contain measured results, dataset counts, or trained weights, so the code leaves those values to the actual experiment.
